# M2 — ensaio pontual de API de produção autorizada

Em 06/11/2026, o PI autorizou consultar uma API própria em produção e seu checkout local. O endereço e o nome do projeto não são versionados aqui. No código da API, `apps/api/src/health/health.controller.ts` define duas rotas públicas: `GET /health/live` responde à vida do processo; `GET /health/ready` consulta separadamente banco, Redis e armazenamento de objetos, devolvendo `200` quando todas estão disponíveis ou `503` quando alguma falha. O teste de integração `apps/api/test/integration/health.int-spec.ts` confirma esse contrato no checkout, mas não foi executado contra produção neste ensaio.

Foram feitas **três requisições GET pontuais** à API de produção, sem cookie, autenticação, redirecionamento, payload ou escrita; cada uma teve timeout de 5 segundos. A leitura direta de `/health/live` devolveu `200` com `status=live`. A leitura direta de `/health/ready` devolveu `200` com `status=ready` e as chaves de dependência `database`, `redis` e `objectStorage` presentes. As durações observadas no cliente foram aproximadamente 535 ms e 604 ms, respectivamente; são duas amostras isoladas, não latência p95.

Em seguida, `httpProbe` consultou `/health/ready` uma vez pelo `CollectorRunner`. O estado foi persistido em SQLite temporário com um projeto e recurso de inventário sanitizados; o snapshot resultou em `health=saudavel`, `freshness=atual`, `coverage=atual` e `evidenceRef=http-status-200`, com um projeto dependente. O banco temporário foi removido após a leitura, com alvo validado dentro da pasta temporária. Nenhuma informação de tenant, conta, sessão ou resposta de negócio foi consultada.

**Limites:** a saúde do banco, Redis e storage é informada indiretamente pela própria API. Este ensaio não abre conexão a essas dependências, não testa falha ou recuperação e não instala coleta periódica da API de produção. A sonda genérica `httpProbe` classifica pelo status HTTP; a forma JSON foi conferida separadamente nesta observação, mas não é validada pela sonda. O Player Unity não foi conectado a essa fonte real. A URL, o inventário de produção e eventuais credenciais ficam fora do Git.
